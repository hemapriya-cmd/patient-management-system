# patient-management-system
A beginner-friendly RESTful Patient Management API built with Python, FastAPI, and Pydantic to manage patient records. Supports CRUD operations, data validation, BMI calculation, health verdicts, sorting, path/query parameters, and error handling. Uses JSON for data storage and FastAPI's Swagger UI for API testing and documentation.

Patient Management System API

A beginner-friendly Patient Management System REST API built using FastAPI and Pydantic.

This project was developed to understand the fundamentals of FastAPI, Pydantic data validation, CRUD operations, API routing, query/path parameters, HTTP exceptions, and computed fields.

Note: This is an educational project. Patient data is stored in a local JSON file and is not intended for real-world healthcare use.

🚀 Features
✅ Create a new patient
✅ View all patients
✅ View a specific patient by ID
✅ Update patient information
✅ Delete a patient
✅ Sort patients by height, weight, or BMI
✅ Automatic BMI calculation
✅ Automatic BMI-based health verdict
✅ Request validation using Pydantic
✅ Path and query parameter validation
✅ HTTP error handling
✅ Automatic interactive API documentation
